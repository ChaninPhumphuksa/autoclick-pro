# Auto Clicker Pro

โปรแกรม Auto Click และเครื่องมือมาโครแบบกำหนดเอง (custom macro) รุ่นโปรเฟชชันแนล
รองรับ Windows / macOS / Linux (ฟีเจอร์ "เริ่มพร้อม Windows" ใช้ได้เฉพาะบน Windows)

## โครงสร้างโปรเจกต์

```
autoclicker_pro/
├── main.py                 จุดเริ่มต้นโปรแกรม
├── requirements.txt        รายการไลบรารีที่ต้องติดตั้ง
├── build_exe.bat           สคริปต์แปลงเป็น .exe (รันบน Windows)
├── assets/
│   ├── icon.png            ไอคอนโปรแกรม (cross-platform)
│   └── icon.ico            ไอคอนสำหรับ Windows
├── core/                   โค้ดตรรกะการทำงาน (ไม่ยุ่งกับ GUI)
│   ├── engine.py           AutoClicker, MacroRecorder, MacroPlayer
│   ├── config.py           บันทึก/โหลดการตั้งค่าแบบถาวร
│   ├── logger.py           ระบบ log ลงไฟล์ (หมุนไฟล์อัตโนมัติ)
│   ├── tray.py             ไอคอน System Tray
│   └── startup.py          เปิดโปรแกรมอัตโนมัติพร้อม Windows
└── gui/                     โค้ดหน้าจอ (Tkinter)
    ├── app.py               หน้าต่างหลัก
    ├── theme.py             ธีม/สไตล์ทันสมัย
    └── dialogs.py           กล่องโต้ตอบต่าง ๆ
```

ข้อมูลผู้ใช้ (การตั้งค่า, มาโครที่บันทึกไว้, log) จะถูกเก็บแยกไว้ที่โฟลเดอร์โปรไฟล์ผู้ใช้
`~/.autoclicker_pro/` เพื่อให้ทำงานถูกต้องแม้ติดตั้งโปรแกรมในโฟลเดอร์ที่เขียนไฟล์ไม่ได้
(เช่น `C:\Program Files\...`)

## วิธีติดตั้งและรัน (โหมดนักพัฒนา / รันด้วย Python)

```bash
pip install -r requirements.txt
python main.py
```

## วิธีแปลงเป็นไฟล์ .exe (แจกจ่ายโดยไม่ต้องลง Python)

ต้องรันบนเครื่อง **Windows** เท่านั้น (PyInstaller ไม่สามารถสร้างไฟล์ .exe
จากเครื่อง Linux/macOS ได้ ต้องรันเครื่องมือบนระบบปฏิบัติการเป้าหมาย):

1. คัดลอกโฟลเดอร์ `autoclicker_pro` ทั้งหมดไปที่เครื่อง Windows
2. ดับเบิลคลิกไฟล์ `build_exe.bat` (หรือรันใน Command Prompt)
3. รอจนเสร็จ จะได้ไฟล์ `dist\AutoClickerPro.exe` — คัดลอกไฟล์นี้ไปใช้ที่เครื่องไหนก็ได้
   โดยไม่ต้องติดตั้ง Python เพิ่ม

## ฟีเจอร์หลัก

- **Auto Click**: ตั้งความถี่ (ชม./นาที/วินาที/มิลลิวินาที), สุ่มความหน่วง (jitter),
  เลือกปุ่มเมาส์, คลิกตำแหน่งปัจจุบันหรือตำแหน่งคงที่, จำกัด/ไม่จำกัดจำนวนครั้ง
- **Macro**: อัดจากการใช้งานจริง หรือสร้าง/แก้ไขขั้นตอนเองทั้งหมดในโปรแกรม
  (เพิ่ม/แก้ไข/ลบ/เรียงลำดับ คลิก-กดปุ่ม-ดีเลย์) พร้อมคลังมาโครแบบตั้งชื่อ
- **Emergency Stop**: ปุ่มหยุดทั้งหมดสีแดงแสดงตลอดเวลา ไม่ว่าจะอยู่แท็บไหน
  และปุ่ม `ESC` หยุดฉุกเฉินได้ทันทีเสมอ
- **Hotkey ที่ตั้งเองได้**: เลือกปุ่ม F1-F12 สำหรับ Auto Click / เล่นมาโคร / อัดมาโคร
- **System Tray**: ย่อโปรแกรมลงถาด ควบคุมจากเมนูคลิกขวาได้โดยไม่ต้องเปิดหน้าต่าง
- **เริ่มพร้อม Windows**: เปิด/ปิดได้จากแท็บตั้งค่า (เฉพาะ Windows)
- **บันทึกการตั้งค่าอัตโนมัติ + Log ไฟล์**: การตั้งค่าและ log การทำงานถูกเก็บไว้
  ใน `~/.autoclicker_pro/` เพื่อการดูแลรักษาแบบมืออาชีพ

## Hotkeys เริ่มต้น

| ปุ่ม | การทำงาน |
|------|-----------|
| F6   | เริ่ม/หยุด Auto Click |
| F7   | เริ่ม/หยุด เล่นมาโคร |
| F8   | เริ่ม/หยุด อัดมาโคร |
| ESC  | หยุดทุกการทำงานทันที (ตายตัว, เปลี่ยนไม่ได้) |

## ข้อควรระวัง

โปรแกรมนี้ควบคุมเมาส์/คีย์บอร์ดจริงบนเครื่อง — ใช้ด้วยความระมัดระวัง โดยเฉพาะโหมด
"วนซ้ำไม่จำกัด" ควรทดสอบกับจำนวนครั้ง/เวลาที่จำกัดก่อนใช้งานจริงเสมอ และจำ hotkey
หยุดฉุกเฉิน (ESC) ไว้เสมอ
