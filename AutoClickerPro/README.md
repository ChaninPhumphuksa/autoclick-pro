# Auto Clicker Pro

โปรแกรม Auto Click และเครื่องมือมาโครแบบกำหนดเอง (custom macro) รุ่นโปรเฟชชันแนล
รองรับ Windows / macOS / Linux (ฟีเจอร์ "เริ่มพร้อม Windows" ใช้ได้เฉพาะบน Windows)

## โครงสร้างโปรเจกต์ (ทุกไฟล์อยู่ที่ root โดยตรง — ไม่มีโฟลเดอร์ย่อยห่อไว้)

```
(repo root)
├── main.py                 จุดเริ่มต้นโปรแกรม
├── requirements.txt        รายการไลบรารีที่ต้องติดตั้ง
├── build_exe.bat           สคริปต์แปลงเป็น .exe (รันบน Windows)
├── .github/workflows/
│   └── build-exe.yml       GitHub Actions: build .exe อัตโนมัติบนคลาวด์
├── assets/
│   ├── icon.png
│   └── icon.ico
├── core/                    ตรรกะการทำงาน (ไม่ยุ่งกับ GUI)
│   ├── engine.py
│   ├── config.py
│   ├── logger.py
│   ├── tray.py
│   └── startup.py
└── gui/                     หน้าจอ (Tkinter)
    ├── app.py
    ├── theme.py
    └── dialogs.py
```

ข้อมูลผู้ใช้ (การตั้งค่า, มาโครที่บันทึกไว้, log) จะถูกเก็บแยกไว้ที่โฟลเดอร์โปรไฟล์ผู้ใช้
`~/.autoclicker_pro/` เพื่อให้ทำงานถูกต้องแม้ติดตั้งโปรแกรมในโฟลเดอร์ที่เขียนไฟล์ไม่ได้

## วิธีที่ 1 (แนะนำ): ได้ไฟล์ .exe โดยไม่ต้องลง Python บนเครื่องตัวเองเลย — ใช้ GitHub Actions

**สำคัญที่สุด:** ไฟล์ทั้งหมดในนี้ (รวมโฟลเดอร์ `.github/` ที่ซ่อนอยู่) ต้องอยู่ที่ **root ของ repo
โดยตรง** ห้ามมีโฟลเดอร์ห่ออีกชั้น เช่น ต้องเป็น `your-repo/main.py` ไม่ใช่
`your-repo/autoclicker_pro/main.py` — ถ้าโครงสร้างผิด workflow จะหาไฟล์ไม่เจอ

ขั้นตอน:

1. สร้าง repository ใหม่บน GitHub (public หรือ private ก็ได้)
2. แตกไฟล์ zip นี้ แล้วลาก**ไฟล์ทั้งหมดข้างในโฟลเดอร์ที่แตกออกมา** (ไม่ใช่ตัวโฟลเดอร์เอง)
   ไปวางที่ root ของ repo แล้ว push/upload ขึ้น GitHub — ต้องเห็นไฟล์ `main.py` อยู่ตรง
   root ทันทีที่เข้า repo (อย่าให้อยู่ลึกในโฟลเดอร์ย่อย)
3. ตรวจว่ามีโฟลเดอร์ `.github/workflows/build-exe.yml` อยู่ใน repo จริง (โฟลเดอร์ที่ขึ้นต้น
   ด้วยจุด `.` มักถูกซ่อนหรือลืมอัปโหลด ให้เปิดแสดงไฟล์ซ่อนก่อน หรือใช้ `git add -A` แทน
   การลากไฟล์ทีละไฟล์)
4. เข้าไปที่แท็บ **Actions** ของ repo — workflow ชื่อ "Build Windows EXE" จะรันอัตโนมัติ
   (หรือกด "Run workflow" เพื่อรันเองก็ได้)
5. รอประมาณ 2-3 นาทีจน build เสร็จ (สถานะจะขึ้นเครื่องหมายถูกสีเขียว) — ถ้าสีแดง (fail)
   คลิกเข้าไปดู log ในสเต็ป "Verify project files exist" จะช่วยบอกว่าตอนนี้ไฟล์อยู่ตรงไหนบ้าง
6. คลิกเข้าไปใน workflow run ที่สำเร็จ เลื่อนลงไปที่ส่วน **Artifacts** จะเจอไฟล์ชื่อ
   `AutoClickerPro-Windows-EXE` กดดาวน์โหลด แตกไฟล์ zip จะได้ `AutoClickerPro.exe`
   พร้อมใช้งานทันที **ไม่ต้องติดตั้ง Python บนเครื่องที่จะใช้งานเลย**

### แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| `Could not open requirements file` | ไฟล์ไม่ได้อยู่ที่ root ของ repo | ย้ายไฟล์ทั้งหมดออกมาไว้ที่ root ตรง ๆ |
| `The directory name is invalid` | workflow อ้างอิงโฟลเดอร์ย่อยที่ไม่มีอยู่จริง | ใช้ไฟล์ `build-exe.yml` เวอร์ชันล่าสุดนี้ (ไม่มี `working-directory` แล้ว) |
| ไม่เจอแท็บ Actions / workflow ไม่รัน | ลืม push โฟลเดอร์ `.github/` (ไฟล์ซ่อน) | เช็คใน repo ว่ามี `.github/workflows/build-exe.yml` จริง หรือ push ด้วย `git add -A` |

## วิธีที่ 2: Build เองบนเครื่อง Windows ที่มี Python อยู่แล้ว

ต้องรันบนเครื่อง **Windows** ที่ติดตั้ง Python ไว้แล้วเท่านั้น (ใช้สำหรับ build เท่านั้น
เครื่องที่จะ "ใช้งาน" ไฟล์ .exe ที่ได้ไม่ต้องมี Python):

1. คัดลอกไฟล์ทั้งหมดในนี้ไปที่เครื่อง Windows (คงโครงสร้างเดิมไว้)
2. ดับเบิลคลิกไฟล์ `build_exe.bat` (หรือรันใน Command Prompt จากโฟลเดอร์นี้)
3. รอจนเสร็จ จะได้ไฟล์ `dist\AutoClickerPro.exe`

## ฟีเจอร์หลัก

- **Auto Click**: ตั้งความถี่ (ชม./นาที/วินาที/มิลลิวินาที), สุ่มความหน่วง (jitter),
  เลือกปุ่มเมาส์, คลิกตำแหน่งปัจจุบันหรือตำแหน่งคงที่, จำกัด/ไม่จำกัดจำนวนครั้ง
- **Macro**: อัดจากการใช้งานจริง หรือสร้าง/แก้ไขขั้นตอนเองทั้งหมดในโปรแกรม
  พร้อมคลังมาโครแบบตั้งชื่อ
- **Emergency Stop**: ปุ่มหยุดทั้งหมดสีแดงแสดงตลอดเวลา + ปุ่ม `ESC` หยุดฉุกเฉินได้ทันที
- **Hotkey ที่ตั้งเองได้**: เลือกปุ่ม F1-F12 สำหรับแต่ละฟังก์ชัน
- **System Tray**: ย่อโปรแกรมลงถาด ควบคุมจากเมนูคลิกขวาได้
- **เริ่มพร้อม Windows**: เปิด/ปิดได้จากแท็บตั้งค่า (เฉพาะ Windows)
- **บันทึกการตั้งค่าอัตโนมัติ + Log ไฟล์**: เก็บไว้ที่ `~/.autoclicker_pro/`

## Hotkeys เริ่มต้น

| ปุ่ม | การทำงาน |
|------|-----------|
| F6   | เริ่ม/หยุด Auto Click |
| F7   | เริ่ม/หยุด เล่นมาโคร |
| F8   | เริ่ม/หยุด อัดมาโคร |
| ESC  | หยุดทุกการทำงานทันที (ตายตัว) |
